Career Suite: tools that keep AI-written CVs honest

Side project · TypeScript, React, Node · built with coding agents · replacing the tools I use for my own job search · 2026

  • A suite of career apps built around one rule: facts are strict, wording is flexible. Every career fact lives once in an evidence bank, and every CV wording has to match the fact it comes from.
  • A bank checker flags wording that adds a number the fact doesn't contain or uses a stronger verb than the fact supports, so AI-written text can't quietly overstate anything.
  • Monorepo with a shared data package (Zod schemas, which also generate JSON Schema for other languages), a shared React UI kit, and a home screen with a small JSON API that starts, stops and monitors every tool.
  • Privacy by design: personal data lives in a separate private repo, so the code can be public.
